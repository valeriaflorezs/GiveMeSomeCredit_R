1 Introducción

Este conjunto de datos Give Me Some Credit, disponible en la plataforma Kaggle. El cual, corresponde a una competencia de predicción del riesgo crediticio, cuyo objetivo es analizar información financiera y de comportamiento de los clientes para determinar la probabilidad de que una persona presente dificultades financieras en el futuro. Asi mismo contiene información relacionada con diferentes características de los clientes, como su edad, ingresos mensuales, número de préstamos, utilización de líneas de crédito, historial de pagos y cantidad de veces que ha presentado retrasos en sus obligaciones financieras.

La variable objetivo del dataset es SeriousDlqin2yrs, que indica si una persona experimentó una situación de morosidad grave durante los siguientes dos años. Esta variable permite plantear el problema como una tarea de clasificación binaria, donde se busca diferenciar entre clientes que presentaron (1) y que no presentaron (0) dificultades financieras graves.

#' Genera una funcion de estilo de celda (para reactable::colDef) que reproduce
#' un degradado de color tipo pandas Styler.background_gradient()
#' @param valores vector numerico sobre el que se calcula el dominio del color
#' @param paleta vector de colores (2 o mas) para scales::col_numeric
#' @param dominio opcional, c(min, max) fijo en vez de range(valores)
estilo_gradiente <- function(valores, paleta, dominio = NULL) {
  rango <- if (is.null(dominio)) range(valores, na.rm = TRUE) else dominio
  mapa_color <- scales::col_numeric(paleta, domain = rango)
  function(value) {
    list(background = mapa_color(value), color = PALETTE$texto)
  }
}

#' Variante de estilo_gradiente() que colorea por VALOR ABSOLUTO pero muestra
#' el valor real (util para asimetria/curtosis, donde lo critico es alejarse
#' de 0 en cualquier direccion). Equivale a gmap=abs(x) en pandas Styler.
estilo_gradiente_abs <- function(valores, paleta) {
  rango <- c(0, max(abs(valores), na.rm = TRUE))
  mapa_color <- scales::col_numeric(paleta, domain = rango)
  function(value) {
    list(background = mapa_color(abs(value)), color = PALETTE$texto)
  }
}

#' Muestra un subconjunto aleatorio (reproducible) para las trazas pesadas de
#' plotly (histogramas/boxplots/violines/parcoords). Las tablas de estadisticos
#' siempre se calculan aparte sobre los datos completos; esto solo aligera el
#' peso de las figuras interactivas cuando n es muy grande (p. ej. 150k filas).
muestra_grafico <- function(x, max_n = 20000, seed = 42) {
  if (NROW(x) <= max_n) return(x)
  set.seed(seed)
  if (is.null(dim(x))) sample(x, max_n) else x[sample(nrow(x), max_n), , drop = FALSE]
}

1.2 Tipo y descripción de las variables

El conjunto de datos está compuesto por variables numéricas y una variable categórica binaria que representa el objetivo del análisis.

  • SeriousDlqin2yrs (Categórica binaria) indica si la persona presentó una morosidad grave durante los siguientes dos años. 0 = No y 1 = Sí.

  • RevolvingUtilizationOfUnsecuredLines (Numérica continua) representa el porcentaje de utilización de las líneas de crédito no garantizadas.

  • age (Numérica discreta) indica la edad de la persona en años.

  • NumberOfTime30-59DaysPastDueNotWorse (Numérica discreta) número de veces que la persona tuvo pagos atrasados entre 30 y 59 días.

  • DebtRatio (Numérica continua) representa la relación entre las obligaciones financieras y los ingresos de la persona.

  • MonthlyIncome (Numérica continua) indica el ingreso mensual de la persona.

  • NumberOfOpenCreditLinesAndLoans (Numérica discreta) cantidad de líneas de crédito y préstamos abiertos.

  • NumberOfTimes90DaysLate (Numérica discreta) número de veces que la persona tuvo pagos con más de 90 días de retraso.

  • NumberRealEstateLoansOrLines (Numérica discreta) cantidad de préstamos o líneas de crédito relacionados con bienes raíces.

  • NumberOfTime60-89DaysPastDueNotWorse (Numérica discreta) número de veces que la persona tuvo pagos atrasados entre 60 y 89 días.

  • NumberOfDependents (Numérica discreta) número de personas que dependen económicamente del cliente.
